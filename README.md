# M-Golf

M-Golf Rapier &amp; Three.js

**Prequisite Software**
You want at least nodejs version `20.19.2`

**Install & Run**

This is a Vite project, below are the commands to run after cloning this repo.

```
npm install
```

```
npm run dev
```

**Resources**
